# 👗 Cara - Modern E-Commerce UI

**Cara** is a sleek, fully responsive, and interactive multi-page e-commerce storefront. This project showcases a modern shopping experience with a focus on clean UI, smooth navigation, and mobile-first responsiveness.

---

🚀 [Live Demo Link](https://harshitmendiratta-18.github.io/frontend-project/E-Commerce%20Website/)

---

## ✨ Features

- **Responsive Design:** Completely optimized for Desktop, Tablet, and Mobile screens.
- **Interactive Product Catalog:** Beautifully designed shop page with hover effects and detailed product views.
- **Dynamic Cart UI:** Professional cart layout with subtotal and coupon application sections.
- **Multi-Page Navigation:** Includes Home, Shop, Blog, About, and Contact pages.
- **Modern UI/UX:** Built with a professional color palette, clean typography, and high-quality imagery.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for better SEO and accessibility.
- **CSS3:** Custom styling with Flexbox, CSS Grid, and Media Queries for responsiveness.
- **JavaScript:** Interactive elements, mobile navigation menu, and dynamic UI updates.
- **Font Awesome:** High-quality vector icons for a premium feel.
